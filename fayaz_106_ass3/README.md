# Library Management System in Dart

A command-line Library Management System built using Object-Oriented Programming (OOP) principles in Dart.

## Features
- **View All Books**: List all books in the library.
- **View Available Books**: Display only books that are currently available.
- **View Borrowed Books**: Display books that have been borrowed.
- **Add a New Book**: Add a new book entry to the library.
- **Borrow a Book**: Borrow a book by its unique ID.
- **Return a Book**: Return a borrowed book by ID.
- **Search Books**: Search books by title keyword.
- **View Statistics**: Summary of total books, available books, borrowed books, and availability percentage.

## How to Run
```bash
dart library_system.dart
```
